## 🎯 О проекте

**GreenShop** — это полнофункциональный интернет-магазин экологичных товаров, разработанный на Django 5.2. Проект демонстрирует современные подходы к разработке e-commerce приложений с акцентом на экологичность и осознанное потребление.

### Основная идея

Предоставить пользователям удобную платформу для покупки экологичных товаров с полной информацией о материалах, сертификатах и производителях. Система рекомендаций помогает найти сопутствующие товары, а интеграция с ЮКассой обеспечивает безопасную оплату.

### Целевая аудитория

- Люди, заботящиеся об экологии
- Приверженцы осознанного потребления
- Покупатели натуральных и экологичных товаров

## 🚀 Установка

### Предварительные требования

Убедитесь, что у вас установлено:

- **Python 3.13+** ([Скачать](https://www.python.org/downloads/))
- **pip** (менеджер пакетов Python)
- **Git** ([Скачать](https://git-scm.com/downloads))

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/yourusername/eco_shop.git
cd eco_shop
```

### Шаг 2: Создание виртуального окружения

**Linux/macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

### Шаг 3: Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 4: Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### Шаг 5: Создание суперпользователя

```bash
python manage.py createsuperuser
```

Введите:
- **Username**: admin
- **Email**: admin@greenshop.ru
- **Password**: (ваш пароль)

### Шаг 6: Генерация тестовых данных

```bash
python manage.py generate_test_data
```

Эта команда создаст:
- ✅ 5 категорий товаров
- ✅ 40+ экологичных товаров с изображениями
- ✅ Тестового администратора (admin / admin123)
- ✅ Тестового пользователя (testuser / test123)
- ✅ Статистику рекомендаций

### Шаг 7: Запуск сервера разработки

```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу: **http://localhost:8000**

### Шаг 8: Доступ к панели администратора

Перейдите по адресу: **http://localhost:8000/admin**

Войдите с креденшелами:
- **Username**: admin
- **Password**: admin123 (или ваш пароль из Шага 5)

## ⚙️ Конфигурация

### Настройки базы данных

По умолчанию используется **SQLite**. Для продакшена рекомендуется **PostgreSQL**.

**SQLite (по умолчанию):**
```python
# eco_shop/settings.py
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

**PostgreSQL:**
```python
# eco_shop/settings.py
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'eco_shop_db',
        'USER': 'your_db_user',
        'PASSWORD': 'your_db_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

### Настройки ЮКассы

Для интеграции с ЮКассой используются тестовые креденшелы:

```python
# eco_shop/settings.py

# Тестовые креденшелы для разработки
YOOKASSA_SHOP_ID = '54401'
YOOKASSA_SECRET_KEY = 'test_Fh8hUAVVBGUGbjmlzba6TB0iyUbos_lueTHE-axOwM0'
YOOKASSA_RETURN_URL = 'http://localhost:8000/payments/success/'

# Тестовая карта для оплаты:
# Номер: 5555555555554477
# Срок: 12/20
# CVV: 000
```

**Для продакшена:**
1. Зарегистрируйтесь на [ЮКасса](https://yookassa.ru/)
2. Получите свои реальные креденшелы (начинаются с `live_`)
3. Замените в `settings.py`

### Настройки email (опционально)

Для отправки email уведомлений:

```python
# eco_shop/settings.py
EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
EMAIL_HOST = 'smtp.gmail.com'
EMAIL_PORT = 587
EMAIL_USE_TLS = True
EMAIL_HOST_USER = 'your-email@gmail.com'
EMAIL_HOST_PASSWORD = 'your-app-password'
DEFAULT_FROM_EMAIL = 'GreenShop <noreply@greenshop.ru>'
```

### Настройки медиа файлов

```python
# eco_shop/settings.py
MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

Не забудьте настроить URL для медиа в разработке:

```python
# eco_shop/urls.py
from django.conf import settings
from django.conf.urls.static import static

if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

### Переменные окружения (рекомендуется для продакшена)

Создайте файл `.env`:

```env
SECRET_KEY=your-secret-key-here
DEBUG=False
ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com

DATABASE_URL=postgresql://user:password@localhost:5432/eco_shop_db

YOOKASSA_SHOP_ID=your-shop-id
YOOKASSA_SECRET_KEY=your-secret-key

EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
```

Установите `python-decouple`:
```bash
pip install python-decouple
```

Используйте в `settings.py`:
```python
from decouple import config

SECRET_KEY = config('SECRET_KEY')
DEBUG = config('DEBUG', default=False, cast=bool)
```

## 💻 Использование

### Работа с товарами

#### Просмотр каталога

1. Перейдите на главную страницу: `http://localhost:8000`
2. Используйте поиск для поиска товаров
3. Примените фильтры по категориям
4. Выберите сортировку (новизна, цена, популярность)

#### Просмотр товара

1. Кликните на карточку товара
2. Изучите детальную информацию, характеристики, сертификаты
3. Посмотрите отзывы других покупателей
4. Ознакомьтесь с похожими товарами и рекомендациями

#### Добавление в корзину

1. Укажите количество товара
2. Нажмите "Добавить в корзину"
3. Товар добавлен! (появится уведомление)

### Оформление заказа

1. Перейдите в корзину (иконка корзины в header)
2. Проверьте содержимое, измените количество при необходимости
3. Нажмите "Оформить заказ"
4. Заполните данные получателя и адрес доставки
5. Выберите способ оплаты:
   - **ЮКасса** — оплата банковской картой онлайн
   - **Наличными при получении**
   - **Картой при получении**
6. Нажмите "Оформить заказ"

### Оплата через ЮКассу

1. После оформления заказа вы будете перенаправлены на страницу ЮКассы
2. Введите данные тестовой карты:
   - **Номер**: 5555555555554477
   - **Срок**: 12/20
   - **CVV**: 000
3. Нажмите "Оплатить"
4. Вы будете перенаправлены на страницу успешной оплаты

### Управление профилем

#### Редактирование профиля

1. Войдите в систему
2. Кликните на ваше имя в навигации
3. Выберите "Профиль"
4. Обновите данные: имя, email, телефон, аватар, дату рождения
5. Сохраните изменения

#### Управление адресами

1. В профиле перейдите в раздел "Адреса доставки"
2. Добавьте новый адрес или отредактируйте существующий
3. Установите адрес по умолчанию для быстрого оформления заказов

#### История заказов

1. Кликните на ваше имя в навигации
2. Выберите "Мои заказы"
3. Просмотрите список всех заказов
4. Кликните на заказ для детальной информации
5. Отмените заказ (если он еще не отправлен)

### Написание отзывов

1. Откройте страницу товара, который вы купили
2. Нажмите "Написать отзыв"
3. Заполните форму:
   - **Рейтинг** (1-5 звезд)
   - **Заголовок**
   - **Текст отзыва**
   - **Достоинства** (опционально)
   - **Недостатки** (опционально)
4. Отправьте отзыв

## 🏗️ Архитектура

### Паттерны проектирования

#### Model-View-Template (MVT)

Django использует паттерн MVT:

- **Model** — описывает структуру данных (модели)
- **View** — содержит бизнес-логику (представления)
- **Template** — определяет отображение (шаблоны)

#### Service Layer

Для сложной бизнес-логики используется Service Layer:

```python
# orders/services.py
class CartService:
    @staticmethod
    def add_to_cart(user, product, quantity):
        # Бизнес-логика добавления в корзину
        pass

class OrderService:
    @staticmethod
    def create_order_from_cart(cart, user, delivery_data, payment_method):
        # Бизнес-логика создания заказа
        pass
```

#### Repository Pattern

Модели Django выступают в роли репозиториев:

```python
# Получение товаров
products = Product.objects.filter(is_available=True)

# Получение товаров с жадной загрузкой
products = Product.objects.select_related('category').prefetch_related('images')
```

### Потоки данных

#### Оформление заказа

```
1. Пользователь → Добавление товара в корзину
                  ↓
2. CartService → Проверка наличия → Добавление CartItem
                  ↓
3. Пользователь → Оформление заказа
                  ↓
4. CheckoutForm → Валидация данных
                  ↓
5. OrderService → Создание Order и OrderItem
                  ↓
6. PaymentService → Создание платежа в ЮКассе
                  ↓
7. Redirect → Страница оплаты ЮКассы
                  ↓
8. Callback → Обновление статуса платежа
                  ↓
9. Redirect → Страница успешной оплаты
```

#### Система рекомендаций

```
1. Пользователь просматривает товар
                  ↓
2. RecommendationService.get_similar_products()
   - Ищет товары из той же категории
   - Исключает текущий товар
   - Сортирует по рейтингу и продажам
                  ↓
3. RecommendationService.get_frequently_bought_together()
   - Ищет в RecommendationStats товары, которые часто покупают вместе
   - Сортирует по частоте
                  ↓
4. Отображение рекомендаций на странице
```

A:
1. Зарегистрируйтесь на yookassa.ru
2. Получите Shop ID и Secret Key
